DRIVEEASE CAR RENTAL WEBSITE
============================

FILES
- index.html  : Website content and booking form
- style.css   : Layout, colours, responsive styling
- script.js   : Menu, car filters, date validation and WhatsApp booking enquiry

HOW TO OPEN IN VISUAL STUDIO CODE
1. Download and extract the ZIP file.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the extracted "car_rental_website" folder.
5. Open index.html.
6. For the easiest preview, install the "Live Server" extension, right-click index.html and choose "Open with Live Server".
   You can also double-click index.html to open it in a browser.

BOOKING BEHAVIOUR
- Visitors select a car and pickup/return dates, enter contact details, and submit the form.
- The form opens WhatsApp with the booking enquiry filled in for +94 76 057 9428.
- The visitor still needs to press Send in WhatsApp.
- The form does not save bookings to a database or confirm availability automatically. To accept and manage bookings automatically, a backend/database or booking service would be needed.
- The displayed cars and rates are example content. Replace them with your actual available cars, photos and prices before publishing.
